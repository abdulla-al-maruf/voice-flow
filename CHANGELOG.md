# Changelog

## 0.3.3: first public release

- Voice engines: offline local Bangla model, Sarvam and Chariot (your own key).
- Setup steps shown inside the app for each engine. "Get key" opens the provider's sign-in page; you paste the key once.
- Local model downloads once (about 71 MB, size and SHA-256 checked), then works without internet.
- Larger text, light menus, black, white and yellow design.
- Last 20 recordings kept with text and audio, encrypted for your Windows user.
- If a paid engine fails, the same recording is read again by the local model when it is installed, and the caption says so.
