# Voice engines

Pick the engine in the main window. The app shows the numbered steps for the one you pick.

## Local model (offline)

1. Press the download button. About 71 MB, once. Internet is needed only for this step.
2. After that it works with no internet and audio never leaves your computer.

Model: SayedShaun/bangla-zipformer-onnx on Hugging Face (CC BY-SA 4.0), run with sherpa-onnx. Accuracy figures published by the model's author are not verified here.

## Sarvam

1. Press "চাবি নিন" (Get key). Sarvam's key page opens in your browser.
2. Sign in, create an API key, copy it.
3. Press "চাবি বসান" (Paste key), paste, save.

Audio is sent to Sarvam and billed to your account.

## Chariot

Same three steps as Sarvam. The dialog also has a verify button that checks the key against Chariot's credit endpoint, which is free.

## Notes

- Keys are encrypted with Windows DPAPI and never logged.
- You can remove a key any time from the same dialog.
- Prices, free credit and language support are set by those companies and can change.
