# Troubleshooting

## Dictation does not start

Look at the engine status in the main window. "মডেল নামানো বাকি" (model not downloaded): press the button once to download the local model (needs internet). "চাবি বাকি" (key missing): press "চাবি নিন" to create a key, then "চাবি বসান" to paste it. Also check the Windows microphone permission and your input device.

## Text was recognized but not inserted

Press Ctrl+V where you want it. If focus changed, the app does not paste into another field by itself. The text is on the clipboard and in the history window.

## Sarvam or Chariot does not work

Check that the key is correct and the account has credit. If it fails and the local model is installed, the same recording is read by the local model and the caption says so.

## A recording is incomplete

Open the history window, listen to the audio, then press "আবার নিন" (Retry). Incomplete text is never pasted into another app by itself.

## No disk space

If a new recording cannot be saved, the last one stays in memory for a while. Free some space and try again. Update and uninstall will not continue while there is an unsaved recording.

## Update or uninstall seems stuck

Finish the current recording and try again. The installer never stops a recording in progress.

## Report a problem

"···" menu, then "সমস্যা জানান". The GitHub issue form opens in your browser. "সমস্যার লগ সংরক্ষণ" saves a sanitized log you can attach (no audio, text or keys). Do not post passwords, keys or private audio in a public issue.
